# Decks mats, presets and zones

Status: immutable mat/preset records and generic-zone implementation with server-side drop effects, 2026-09-21.

Presets pin immutable template/mat versions and generic configuration. They never contain old session cards, random results or private hand contents. Authenticated owners create immutable mat versions and table presets through `/api/mats` and `/api/presets`; `/api/mats-and-presets` lists only the caller's records. The `configure_table` action validates an owned preset, persists its immutable reference and configuration, and copies its named zones into the lobby session. `create_zone`/`delete_zone` persist host-owned zones with positive rectangle geometry, priority and allowlisted behavior. Snapshots expose the selected configuration and authorized zones to table members. Supported drop effects are `none`, `face_up`, `face_down`, `stack`, `align`, `fan`, and `owner_private`; they are applied server-side when a card is placed on the table, moved as a group, or played from a hand. A zone has a name, geometry and explicit priority. If a card center is inside multiple zones, the highest priority wins, then the smallest area; equal-ranked conflicting effects are rejected rather than guessed. `owner_private` assigns the placing actor as the only card-definition viewer. Spatial zones never replace logical card containment. Zone effects are applied in the same durable action transaction and projected through the viewer's privacy rules.
