# Decks mats, presets and zones

Status: generic-zone implementation with server-side drop effects, 2026-09-21. The MVP stores generic session piles and table positions; mats and immutable presets remain a later extension.

Presets pin immutable template/mat versions and generic configuration. They never contain old session cards, random results or private hand contents. The current `configure_table` action persists an allowlisted lobby mat label/color and optional preset UUID in `sessions.access_settings`; `create_zone`/`delete_zone` persist a host-owned zone name, positive rectangle geometry, priority and allowlisted behavior in the session transaction. Snapshots expose that configuration to table members. Supported drop effects are `none`, `face_up`, `face_down`, `stack`, and `align`; they are applied server-side when a card is placed on the table, moved as a group, or played from a hand. A zone has a name, geometry and explicit priority. If a card center is inside multiple zones, the highest priority wins; an equal-priority conflicting effect is rejected rather than guessed. Spatial zones never replace logical card containment. Zone effects are applied in the same durable action transaction and projected through the viewer's privacy rules.
